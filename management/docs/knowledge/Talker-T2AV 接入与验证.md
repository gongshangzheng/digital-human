## 一、接入目标

本地接入的目标是把固定上游 Talker-T2AV 版本接入 `digital_human` 的 speed-run/评测框架：能下载或定位权重、准备参考输入、运行推理、保存可追溯输出，并与其他模型共用基本的产物结构。

本地 adapter 以七阶段组织，覆盖输入检查、参考元数据、模型调用、音视频输出、结果记录等。它提供的是**实验入口**，不代表任何 A2V 或质量结论已经成立。

## 二、权重、环境与兼容层

运行需要三组权重：

| 组件 | 本地状态/用途 |
|------|---------------|
| Talker-T2AV + WhisperX-VAE | 主 checkpoint 与语音 latent 解码 |
| LIA-X | 视频 motion autoencoder 权重 |
| WavLM speaker encoder | 参考音频的说话人/风格条件 |

接入中还处理了：SDPA 回退、WavLM 离线预构造、soundfile 落盘，以及上游复刻环境 pin（`configs/envs/talker_t2av.txt`）。权重下载脚本规划约 **17.4GB**，首次运行还可能触发上游 WavLM 的缓存下载。

当前本机没有完整 `pretrained/talker_t2av` 与 `.envs/talker_t2av`，因此任何新的结果都必须记录实际权重 SHA、环境和 GPU，而不能复用历史 smoke 当作当前机器结果。

## 三、输出规格演进：512²不是最终交付规格

接入经历过三种形态：

```text
先裁方 / 直接输出512²
  → 512²直出裁决
  → 逐帧 FaceCropper 对齐
  → 贴回源视频分辨率（当前）
```

当前代码中 **512×512 是中间生成尺寸**。FaceCropper 对每帧做对齐与贴回，最终输出跟随源视频分辨率。旧 reference 文档中仍有“输出512²”的写法，属于过时描述，不能作为当前接口事实。

## 四、已验证：历史可运行性冒烟

历史 speed-run 冒烟记录：官方样例 **3.04 秒 / 76 帧**，RTF **21.33**、峰值显存 **15.0GB**。这说明当时 adapter、权重和推理链能够跑通；同时也说明该口径**远未实时**：RTF 21.33 意味着生成 1 秒内容约需 21 秒墙钟时间。

| 已验证 | 还没有验证 |
|--------|------------|
| 上游样例可运行 | 当前环境是否可复现 |
| 产物链可输出音视频 | 人工视觉质量 |
| 基本权重/依赖路径曾可用 | 与 Ditto/AF 的公平质量比较 |
| 512²中间生成可走到贴回 | A2V 能力、FaceCropper gate、正式指标 |

## 五、下一次复跑的最小协议

为了让结果能进入模型比较，而不是只留一段 demo，需要同时保存：

- 上游 commit、Talker checkpoint/LIA-X/WavLM 权重 SHA；
- 环境、GPU、显存、精度和完整命令；
- 目标文本、参考音频、参考 motion/视频；
- `gt-prefix-seconds`、输出源分辨率、帧率、时长；
- 原始输出、日志、RTF、峰值显存；
- FaceCropper 是否通过官方/真人 gate；
- 人工视觉结论和同协议对照视频。

A2V 公平比较要额外谨慎：固定版本公开 CLI 的主路径是 T2AV，不能因为上游 README 宣称 A2V 就把未验证的 A2V 分数与 Ditto/AF 的 audio-driven 输出直接比较。

## 面试追问预案

**Q：为什么模型接入成功却不能立刻写“效果可用”？**

接入成功只证明依赖、权重和 adapter 能把一次推理走完。效果可用还需要定义场景、同协议输入、性能预算、指标和人工观察。T2AV 当前只有历史 smoke，RTF 21.33 还直接说明它不适合作为实时结果宣传；把“能跑”写成“可用”会掩盖最重要的验证缺口。

**Q：FaceCropper 为什么会影响模型比较？**

FaceCropper 改变输入/输出几何：先前512²直出和当前逐帧对齐贴回源分辨率不是同一种交付物。若一个模型输出512裁图、另一个输出原分辨率贴回视频，直接比较画质、身份或性能会混入裁剪与编码差异。因此复跑时必须把 FaceCropper版本和输出规格写进协议。

**Q：T2AV 的 RTF21.33 是否代表模型没有价值？**

不代表。它只说明这次特定硬件、权重、环境和输入下的性能不满足实时。T2AV 的价值可能在文本控制、联合音视频生成和风格延续；是否适合实时、离线内容生成或某个特定业务，需要分别用性能和质量证据判断。
