## 统一模板

- 论文层 `## 是什么`：论文/机构/年份/一句话定位、arxiv id、papers 库链接
- 论文层 `## 架构核心`：驱动信号→表示→生成→渲染链路 + 与同类差异一表
- **可选工程层** `## 在我们体系中的角色`：CyberVerse 插件路径 @4968280、接入状态、我们的改动/优化/否证记录（仅深度接入过的模型填写，主视角"我们怎么用的"）
- `## 与复盘各线的关联` / `## 参考与延伸`：knowledge/ 精读链接、papers 库条目
