## 一句话总结

**把「人是谁」与「人在怎么动」彻底拆开：身份是源图独有的 canonical 3D 关键点，运动只由「头姿 $R,t$ + 表情形变 $\delta$」描述——身份跨帧复用，于是每帧只需传运动，既能在原视角邻域内自由改视角，又能把视频会议的带宽压到传统编码器的一成。**

- **纯神经渲染**：不用 3DMM 等 3D 图形模型，只用深度网络从单张源图 $s$ 与驱动视频 $\{d_i\}$ 合成输出 $\{y_i\}$（§3）。
- **无监督可分解 3D 关键点**：每个关键点分解为身份几何签名 $x_{c,k}$、头姿 $R,t$、表情形变 $\delta_{k}$ 三项（Eq. 1/Eq. 2），全部无监督学出。
- **局部自由视角（free-view）**：合成时对驱动头姿叠加用户指定的 $R_u,t_u$，即在原始视角的大邻域内转动头部（§3.2；贡献 2）。
- **低带宽**：每帧只需 $3K+6$ 个标量，配合熵编码与自适应关键点数，相对 H.264 CRF36 得到 **10.37×**（自适应）/ **6.5×**（20 关键点）带宽下降（§5；贡献 3）。
- **质量**：在 VoxCeleb2 与 TalkingHead-1KH 上，同身份重建与跨身份迁移的全部报告指标均优于 fs-vid2vid、FOMM、FOMM-L、Bi-layer（Table 1/2/4）。

## 问题与动机

任务设定：给定一张源图 $s$ 与一段驱动视频 $\{d_1,\dots,d_N\}$，合成输出视频 $\{y_1,\dots,y_N\}$——**身份继承自 $s$，运动来自 $d_i$**。当 $s$ 取驱动视频自身的一帧（如 $s\equiv d_1$）时是视频重建，否则是运动迁移（§3）。

已有路线各有缺口（§1、§2）：

| 路线 | 做法 | 论文指出的缺口 |
|---|---|---|
| 3D 图形模型路线（3DMM 等） | 用 3D 人脸模型驱动 | 内脸区域好，但**难以合成头发、胡须、牙齿、眼镜/帽子/围巾**等区域与配饰 |
| 2D 关键点路线（FOMM [68]、fs-vid2vid [82]、Bi-layer [92]） | 2D 稀疏关键点 + 局部仿射 warp | **只能从原始视角合成**，无法表达 3D 姿态、不能自由改视角 |

论文的 insight 是把运动表示拆开：**身份（canonical 关键点）与运动（头姿 + 表情形变）解耦**。解耦之后有两件事同时成立——对身份表示施加 3D 变换就能改视角；只传运动项就能降带宽。

两个直接动机数据：

1. **视角**：视频会议里人们期望「面对面」的临场感，固定正视角的合成无法模拟转头（§1）。
2. **带宽**：人们在意画质但带宽有限，本文的紧凑关键点表示目标是在同等观感下把带宽降一个数量级（Abstract；§5）。

## 方法精析

主链路分三步（§3；图 1）：**源图特征提取 → 驱动帧特征提取 → 视频生成**。外观来自源图一次编码，运动逐帧提取，生成器把源图外观按驱动运动重排成画面。

这张图是**我们口径的结构图**（论文原图偏重作者想强调的标注），它把三件在散文里容易被拆散的事画在一起：

1. **缓存边界**：源侧四个量（$f_s$、$x_{c,k}$、$R_s,t_s$、$\delta_{s,k}$）只在会话开头算一次，**不进码流**；驱动侧每帧只跑 $H,\Delta$。左边那个框就是「带宽为什么能降一个数量级」的结构原因。
2. **身份只能从源图来**：驱动侧**不跑** $L$，直接复用同一组 $x_{c,k}$——所以输出身份必然等于源图，这不是损失函数约束出来的，是拓扑上就排除掉的。
3. **warp 两次**：先用 $K$ 条流各自 warp 一份 $f_s$ 送给 $M$ 求掩码（解决「$K$ 个局部模型谁说了算」），再用合成流 $w$ warp 一次送给 $G$（解决「造不出新像素」）；free-view 那条虚线则是「改运动档位 = 改视角」——它只动 $R_d,t_d$，不动外观体。

### 源/驱动两路特征提取与三项分解

源图侧有四个网络（§3.1）：外观特征提取网络 $F$ 把 $s$ 编成 **3D 外观特征体 $f_s$**（含宽/高/深三个空间维度，映射到 3D 体是对关键点做旋转/平移的前提；**按 Fig. 12 的配置串可读出其形状**：`1×1-Conv-16384` 后 `Reshape C16384 → C1024×D16`（$16384=1024\times16$，即**深度 16**），末端 `1×1-Conv-512` 后 `Reshape C512 → D16×C32`（$512=16\times32$，即**最终 32 通道**）；**空间分辨率论文未给出**，只能从下采样块数推）；canonical 关键点检测网络 $L$ 从 $s$ 提取 $K$ 个 **canonical 3D 关键点 $x_{c,k}\in\mathbb{R}^3$**（默认 $K=20$）；头姿估计网络 $H$ 给出 $R_s\in\mathbb{R}^{3\times3}$、$t_s\in\mathbb{R}^3$；表情形变估计网络 $\Delta$ 给出 $K$ 个形变 $\delta_{s,k}$。由此合成源关键点：

$$
x_{s,k}=T(x_{c,k},R_{s},t_{s},\delta_{s,k})\equiv R_{s}x_{c,k}+t_{s}+\delta_{s,k}
$$

| 符号 | 含义 |
|---|---|
| $x_{c,k}\in\mathbb{R}^{3}$ | 第 $k$ 个 canonical 3D 关键点，只编码中性姿态/表情下的身份几何签名 |
| $R_{s}\in\mathbb{R}^{3\times3}$、$t_{s}\in\mathbb{R}^{3}$ | 源图头部旋转与平移 |
| $\delta_{s,k}$ | 源图相对中性表情的关键点形变 |
| $T(\cdot)$ | 由三部分组合出图像特异关键点的变换 |
| $x_{s,k}$ | 源图特有（image-specific）关键点 |

等式右端直接读出三项分解：**身份 $x_{c,k}$ + 姿态 $R_s,t_s$ + 表情 $\delta_{s,k}$**。论文强调 $x_{c,k}$ 是**无监督学到的、不同于常见人脸 landmark**，被约束为与姿态/表情无关。

![图 2 · 源/驱动两路特征提取：(a) 源图取外观特征与 3D canonical 关键点、估头姿与表情形变算源关键点；(b) 驱动图复用 canonical 关键点、只估头姿与表情形变算驱动关键点（论文 Figure 3）](/api/management/docs-assets/face-vid2vid/fig-2-feature-extraction.webp)

图 2（论文 Figure 3）把两路的差别画清楚：驱动侧**不再用 $L$ 重新检测 canonical 关键点**，而是复用源图的 $x_{c,k}$，只估 $R_d,t_d$ 与 $\delta_{d,k}$——因为输出身份必须等于源图。这也是「只传运动」能成立的结构原因。由此得驱动关键点：

$$
x_{d,k}=T(x_{c,k},R_{d},t_{d},\delta_{d,k})=R_{d}x_{c,k}+t_{d}+\delta_{d,k}
$$

| 符号 | 含义 |
|---|---|
| $R_{d}\in\mathbb{R}^{3\times3}$、$t_{d}\in\mathbb{R}^{3}$ | 驱动帧头部旋转与平移 |
| $\delta_{d,k}$ | 驱动帧表情形变 |
| $x_{d,k}$ | 驱动帧关键点；与 $x_{s,k}$ 共用同一组 $x_{c,k}$ |

**与 FOMM 的关键机制差异**：本文**不估计 Jacobian**。FOMM 用每个关键点的 Jacobian 描述局部块的仿射变换，需要每帧传输；本文假设头部近似刚体，局部块变换直接由头旋转给出 $J_{s}=R_{s}$，因此省掉 Jacobian 传输（§3.1）。

![图 3 · 关键点计算流水线：每步只展示前 5 个关键点与其合成图；canonical（b）→ 施加驱动旋转平移（c）→ 表情形变（d），并展示 canonical 关键点的分布（同人不同姿态相似、不同人同姿态不同）（论文 Figure 4）](/api/management/docs-assets/face-vid2vid/fig-3-keypoint-pipeline.webp)

图 3（论文 Figure 4）是「3D 隐式关键点到底在做什么」唯一的直观证据：论文按步骤**只保留前 5 个关键点**去合成，说明每个点携带的信息量随点数增加而累积；下方两块展示 canonical 关键点的分布——**同一个人在不同姿态下相似、不同人在同一姿态下不同**，这正是「canonical 关键点只编码身份」这一定性的实验性支撑（论文未给分布的距离指标，属定性证据）。

### 视频生成：K 个流 → 合成掩码 → warp → 生成器

生成侧把关键点变成画面（§3.3；App A.1）：

1. 对第 $k$ 个关键点，用一阶近似 [68] 计算 warp flow $w_k$（可靠范围仅关键点邻域）。其映射为 $w_{k}:R_{s}R_{d}^{-1}(p_{d}-x_{d,k})+x_{s,k}\mapsto p_{s}$（Eq. 4），即把驱动 3D 坐标 $p_d$ 映到源 3D 坐标 $p_s$。
2. 用全部 $K$ 个 flow 分别 warp 外观特征 $f_s$ 得 $w_k(f_s)$；拼接后送 **3D U-Net**，再用 softmax 得 **flow 组合掩码 $m=\{m_1,\dots,m_K\}$**。
3. 线性合成最终 flow：
4. 为处理 warp 遮挡，运动场估计网络 $M$ 额外预测 2D **遮挡掩码 $o$** 交给生成器 $G$；$G$ 把 warp 后的 3D 特征投影回 2D、乘 $o$，再经 2D residual block 与上采样输出图像 $y$。

$$
w=\sum_{k=1}^{K}m_{k}(p_{d})\,w_{k}(p_{d}),\qquad \sum_{k}m_{k}(p_{d})=1,\quad 0\leq m_{k}(p_{d})\leq 1
$$

| 符号 | 含义 |
|---|---|
| $w_k$ | 第 $k$ 个关键点诱导的一阶近似流场 |
| $m_k\in[0,1]$ | 第 $k$ 个流在 3D 位置 $p_d$ 上的组合权重（softmax 输出，对 $k$ 求和为 1） |
| $w$ | 线性合成后的最终流场 |
| $p_{d}$、$p_{s}$ | 驱动 / 源 3D 特征体中的坐标 |
| $o$ | 2D 遮挡掩码，补偿 warp 引起的遮挡 |

这条「K 个一阶流 + softmax 掩码线性组合」的构造与 FOMM 同源（论文显式引用 [68]），差别仍在前端：这里的流由 3D 关键点对给出，而不是 2D 关键点 + Jacobian。**本篇只写 Face Vid2vid 自身的机制**；LivePortrait 对这套构造的升级（尺度因子、级联损失、stitching/retargeting）归其本笔记。

### 损失函数

训练目标是 6 项加权和（Eq. 3 为不计权重的清单，Eq. 6 加权重）：

$$
\begin{aligned}
\mathcal{L}=\;&\lambda_{P}\mathcal{L}_{P}(d,y)+\lambda_{G}\mathcal{L}_{G}(d,y)+\lambda_{E}\mathcal{L}_{E}(\{x_{d,k}\})\\
&+\lambda_{L}\mathcal{L}_{L}(\{x_{d,k}\})+\lambda_{H}\mathcal{L}_{H}(R_{d},\bar{R}_{d})+\lambda_{\Delta}\mathcal{L}_{\Delta}(\{\delta_{d,k}\})
\end{aligned}
$$

| 符号 | 含义 | 实现要点 |
|---|---|---|
| $\mathcal{L}_{P}$ | 感知损失 | 多尺度 VGG19（层 `relu_1_1…relu_5_1`，权重 **0.03125 / 0.0625 / 0.125 / 0.25 / 1.0**，重复 3 次多分辨率）+ 单尺度人脸 VGG [59] |
| $\mathcal{L}_{G}$ | GAN 损失 | patch GAN [84,58] + hinge loss + 判别器 feature matching；256×256 用单尺度判别器，512×512 用双尺度 [84] |
| $\mathcal{L}_{E}$ | 等变损失 | 对图施加已知 2D 变换（仿射 + 随机薄板样条），关键点应按同变换改变：$\lVert x_{d}-\mathbf{T}^{-1}(x_{\mathbf{T}(d)})\rVert_{1}$ |
| $\mathcal{L}_{L}$ | 关键点先验损失 | 覆盖损失（防关键点聚集）+ 深度先验；阈值 $D_t=0.1$、目标平均深度 $z_t=0.33$（Eq. 5） |
| $\mathcal{L}_{H}$ | 头姿损失 | $\lVert R_{d}-\bar{R}_{d}\rVert_{1}$（按欧拉角差求和），$\bar{R}_{d}$ 来自预训练姿态网 [66] 作伪真值 |
| $\mathcal{L}_{\Delta}$ | 形变先验损失 | $\lVert\delta_{d,k}\rVert_{1}$，约束形变为小量 |
| $\lambda_{*}$ | 六项权重 | $10,1,20,10,20,5$ |

> **事实核对注（一处表述不一致）**。等变损失把 3D 关键点投回 2D 的方式，正文 §3.4 写「orthographic projection」，App A.2 写「直接丢弃 $z$ 值」；两说应等价或近似，但论文本身表述不一致，引用时需注明。

## 推理与系统链路

推理是「源图编码一次 + 驱动帧逐帧取运动」：源侧算 $f_s,x_{c,k},R_s,t_s,\delta_{s,k}$ 一次；驱动侧逐帧用 $H,\Delta$ 得 $R_d,t_d,\delta_{d,k}$，与 $x_{c,k}$ 合成 $x_{d,k}$ 后进生成器（§3.2）。

### 局部自由视角（free-view）

用户给定旋转/平移偏移 $R_u,t_u$ 后，直接改写驱动头姿：$R_{d}\leftarrow R_{u}R_{d}$、$t_{d}\leftarrow t_{u}+t_{d}$（$R_u,t_u$ 为用户的额外旋转/平移，$R_d,t_d$ 为驱动帧原始头姿）。

因为 $x_{c,k}$ 只携带身份几何，对它施加新的 3D 变换就等于把头部转到新视角——这是「改运动档位就能改视角」的直接原因。论文只称有效范围是原始视角的「大邻域（large neighborhood）」，**可旋转角度上限未量化**（§3.1、§3.2）。

### 视频会议压缩框架

![图 4 · 视频会议压缩框架：发送端只提取关键点扰动 δ 与头姿 R,t 经熵编码发出，接收端与源图 s 一起重建；接收端还可用姿态偏移 R_u,t_u 改头姿（论文 Figure 10）](/api/management/docs-assets/face-vid2vid/fig-4-compression.webp)

图 4（论文 Figure 10）是本文区别于纯动画工作的部分：**传输的是关键点元数据而不是像素**。发送端用 driving image encoder（$H+\Delta$）取 $\delta_{d,k}$ 与 $R_d,t_d$；旋转用 Euler 角表示，故每帧只需 $3K+6$ 个数（3 旋转 + 3 平移 + $3K$ 形变），经算术编码（entropy coder [40]）发送；接收端解码后与源图 $s$ 一起重建 $d$。源图 $s$ **只在会话开始传一次或复用旧会话**，不占每帧带宽；论文特别澄清**源图 ≠ I 帧**（I 帧在会议中频繁发送）。

```mermaid
flowchart LR
  D["驱动帧 d"] --> ENC["driving encoder：H + Δ"]
  ENC --> META["每帧元数据：$$R_d, t_d, \delta_{d,k}$$（$$3K+6$$ 个标量）"]
  META --> AC["arithmetic encoder（熵编码）"]
  AC --> NET(["传输：自适应方案平均 53.03 B/帧"])
  NET --> AD["arithmetic decoder"]
  AD --> SYN["合成：K 个流 → 掩码 m → warp → 生成器 G"]
  S["源图 s（会话开始只传一次）"] --> SYN
  POS["用户姿态偏移 $$R_u, t_u$$"] --> SYN
  SYN --> OUT["重建图 y（驱动帧 d 的还原）"]
```

时序上只有源图编码是一次性的，其余逐帧进行；姿态偏移在**接收端**施加，意味着接收方可以本地改视角而不额外耗带宽。

两个为省码率设计的机制（§5；App C.2、C.3）：

- **自适应关键点数**：训练时对有序关键点数组做尾部 dropout（比例 0%–75%），推理时按带宽动态少用关键点；平均发送点数由 $K=20$ 降到 **11.52**。
- **二进制残差编码**：内容剧变（新物体、换人等）时，用 3 层 stride-2、32 通道卷积网编码 512×512 残差，取 $32\times64\times64$ latent 的符号得二值码，解码器用 3 层 128 滤波器 + pixel shuffle；算术编码后平均 **13.40 KB**，**非每帧发送**，仅在当前源图不足以重建当前驱动帧时发送。

**关联网**：这条「只传运动档位、像素在两端各自渲染」的链路与 [[数字人概述/工程设计|工程设计]] 里的传输/带宽议题同源——它把带宽预算从「像素码率」换成「运动元数据码率」。

## 实验与结果

## 相关工作与定位

| 方法 | 关键点维度 | 是否估 Jacobian | 表示分解 | 自由视角 | 每帧传输 |
|---|---|---|---|---|---|
| FOMM [68] | 2D | 是（每点 Jacobian） | 无显式分解 | ✗ | 关键点 + Jacobian |
| fs-vid2vid [82] | 2D landmarks | — | 无 | ✗ | 完整关键点 |
| Bi-layer [92] | — | — | 高低频分解 | ✗ | — |
| 3DMM 类 [57,55,20,19] | 3D 模型 | — | 显式 3D 模型 | ✗（固定视角） | — |
| pSp [64] / RaR [99] | — | — | latent / 3D 旋转 | 只做正面化 | — |
| **本文** | **3D 隐式** | **否，$J_s=R_s$** | **身份 + 姿态 + 表情** | **✓（$R_u,t_u$）** | **$3K+6$ 标量** |

- **2D 关键点线**（FOMM、fs-vid2vid、Bi-layer）用 2D 关键点做 warp，效率高但不能表达 3D 姿态；本文换成 3D 隐式关键点并显式三项分解，代价与机制差异都落在这一处。
- **正面化线**（pSp、RaR）是 face redirection 的直接对照：pSp 总能转正但身份常丢，RaR 视觉更吸引人但内脸区域之外有问题；论文称只有本文能真实地把输入正面化（§4.2）。
- **与 3D 图形模型路线**的差异是本文刻意不打 3DMM：纯神经渲染更适合头发/牙齿/配饰，且本文补上了它缺的自由视角。

**与本仓库谱系**：这条线是「隐式 3D 关键点 + 光流 warp + 生成器」范式的转折点，表示层的传承为 **Face Vid2vid → LivePortrait → Ditto**——本文确立 $x_{c,k}$ / $R,t$ / $\delta$ 三分解与「不估 Jacobian」；LivePortrait 在此之上加尺度因子与可插拔控制模块；Ditto 再把 265 维运动空间搬进扩散主干。

## 局限与启发

### 论文自己承认的局限

- **有明显遮挡物时失败**。论文明确写「当图中出现手这类遮挡物时仍会失败」，失败案例集中在遮挡与图像退化（App B.5；Fig. 14）。
- **正面化 Angle 指标落后 pSp**（90.9 vs 99.8），论文未解释（见实验节事实核对注）。
- **未量化的 free-view 范围**：只称原始视角的「大邻域」，可旋转角度上限未给出。
- **多处复现缺口**：网络宽度与空间分辨率、$G$ 的投影算子、$o$ 的监督方式、batch size、学习率 schedule、随机种子、参数量均未披露（见训练节）；**深度不属此列**——$f_s$ 的深度 16 与末端 32 通道可从 Fig. 12 的 reshape 串读出，缺的是空间分辨率。

![图 6 · 失败案例：有明显遮挡物（如手）时合成质量下降（论文 Figure 14）](/api/management/docs-assets/face-vid2vid/fig-6-failure.webp)

图 6（论文 Figure 14）是失败案例的直接视觉证据：出现遮挡物时，遮挡区域不在隐式关键点能表达的范围内，warp 与掩码无法正确搬运该区域，因而失败。它比文字更可检验——这是我们判断「这条方法在什么素材上不可用」的锚点。

| 论文承认的问题 | 我们的结论 |
|---|---|
| 有手等遮挡物时失败 | **未接入**，无第一手结论；只把它记为「素材选择边界」——输入不应含明显手部遮挡 |
| 正面化 Angle 落后 pSp、论文未解释 | **未接入**，无第一手结论；本篇只照录 + 标注，保留该例外 |

| free-view 范围未量化 | **未接入**，无第一手结论 |
| 复现缺口（网络细节、训练超参、投影/监督未披露） | **未接入**，无第一手结论；这也是本仓库只复用它的**表示与运动分解**、不自建训练链路的原因之一 |

### 可操作启发

1. **可分解的运动表示是最值钱的部分**。把「身份 / 姿态 / 表情」拆开，等于同时打开了两个原本互斥的能力——姿态可编辑与低带宽传输。这条思路比任何具体网络结构都更值得被后续工作继承。
2. **不估 Jacobian 换来的不只是省参数**。假设头部近似刚体、令 $J_s=R_s$，每帧省掉 Jacobian 传输，是带宽能进一步下降的关键一环——「机制层面的假设」常常比「工程层面的压缩」更省。
3. **消融要盯着非数值代价**。direct prediction 定量只差一点，但丢掉了姿态控制；只看指标会漏掉这种「能力级」的退步。
4. **诚实标注异常值**。`Nan` 与 Angle 落后都属于「不替论文解释」，保留原值与例外，是引用纪律的一部分。

| $m=\{m_k\}$ | flow 组合掩码（softmax 输出，和为 1） |
| $o$ | 2D 遮挡掩码 |
| $p_d$ / $p_s$ | 驱动 / 源 3D 特征体坐标 |
| $F,L,H,\Delta,M,G$ | 外观 / canonical 关键点 / 头姿 / 形变 / 运动场 / 生成器网络 |
| $\mathcal{L}_{P},\mathcal{L}_{G},\mathcal{L}_{E},\mathcal{L}_{L},\mathcal{L}_{H},\mathcal{L}_{\Delta}$ | 感知 / GAN / 等变 / 关键点先验 / 头姿 / 形变先验损失 |
| $\bar{R}_{d}$ | 预训练姿态网 [66] 给出的伪真值旋转 |
| $D_t,z_t$ | 关键点最小间距阈值 0.1、目标平均深度 0.33 |
| $\lambda_{*}$ | 六项损失权重（10,1,20,10,20,5） |
| $3K+6$ | 每帧传输的标量数（3 旋转 + 3 平移 + $3K$ 形变） |

**易混提示**：$M$ 既是运动场估计网络字母，又出现在指标名 `MS-SSIM` 中；$T$（关键点合成变换）与 $\mathbf{T}$（等变损失里的 2D 变换）是两个不同对象；`fs-vid2vid`（few-shot）与本文（one-shot）是不同的方法。
