## Why

> **顶层命题**：**如何从一条自然的表情变化轨迹（或一个角色的视频）中，学出这个角色特有的【运动先验 / 风格】，并把它用于生成时的约束与引导。**

锚点（本仓库自有）：`数字人概述/数字人领域问题` §一 `### 说话风格：从几张图或一段视频学到"这个人怎么说话"` —— 它已给出三种入口与缺口"让风格、身份、语义与情绪在同一生成中可分离地进入条件"。


三轮 brainstorming + 两轮文献实测调研把方向钉成了两件事：**共享动作空间 + 逐角色特化**，以及**只剩一格未被占据**的位置——*在动作隐变量的**输出侧**建一个逐角色的运动先验，并用它引导生成来治身份漂移*。

本轮又完成一次关键转向：**不再"手工拟合流形几何"，改为"学一个逐角色的运动先验 $p(\alpha)$"**。因为手工拟合几何要求先验选定形状（线性/锥/椭球），是两步手工管线；而"可打分 + 可采样"本就是密度模型的能力。**流形降级为密度的水平集（解释），不是实现**；判定 = 密度分位，越界量 = $-\log p$，投影 = 沿 $\nabla\log p$ 上升，约束强度 = 引导权重 $w$。而 A1 的锚帧库**本质就是非参数密度估计**——所以这是一条**升级路，不是推翻重来**。

材料现在散在三处：`数字人概述/` 的既有证据线、`论文笔记/` 的单篇笔记、change 内的两份调研。缺一个**主题层**把它们收在一起。
