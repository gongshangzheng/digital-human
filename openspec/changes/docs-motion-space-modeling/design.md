### 共享上游命题（与 `docs-identity-consistent-learning` 共同持有；**双向必须同步**）

> **身份 = 一条轨迹里【不变】的部分；运动风格 = 这条轨迹里【变化】的部分。**

一条轨迹 $\alpha_{1:T}$ 的分解：

$$\alpha_{1:T}\;\xrightarrow{\ \text{分解}\ }\;\big(\underbrace{s}_{\text{轨迹里【不变】的部分}},\ \underbrace{\{\alpha_t\}}_{\text{轨迹里【变化】的部分}}\big)$$

**两件事是同一个分解问题的两个输出** —— 这解释了为什么它们总是纠缠（`数字人领域问题` §一 `### 说话风格` 原话：「身份回答'是谁'，风格回答'这个人怎样说话、怎样动'。**两者容易纠缠**」）。

**为什么两个 change 共享它**：素材同一份（一段视频），且**物理上真的耦合**（「脸型决定了笑起来什么样」）—— 强行拆干净反而失真。正解是 **共享表示 + 解耦约束**（disentangled representation 的标准范式：共享底层 + 独立分量 + 约束）。他们已在旁边见过这个套路：EDTalk++ 的**四个正交空间** · PSM 的**逐人 vs 通用两层**。

**⚠ 但分界不是先验给定的**：

```
低头 / 抬头幅度   算「不变」（身份）还是「变化」（风格）？
脸部尺度变化      算身份漂移还是风格？
眨眼频率          算身份还是习惯？
```

**这正是实测里「模长 / 方向 / 尺度」三条漂移曲线之所以有歧义的根源** —— 不是测得不准，是**分界本身没定义**。

> **「划分线在哪里」本身就是本方向要研究的第一个对象**，不是可以假定的前提。

**分解质量的三条指标（取代「另造一把尺子」）**：

| # | 指标 | 负责侧 |
|---|------|-------|
| **①** | **不变分量确实不变**（沿轨迹方差小） | 身份侧 |
| **②** | **变化分量确实承载风格**（跨角色可分） | 风格侧 |
| **③** ★ | **两者不互相渗透**（交换任一分量，另一分量统计不变） | 解耦侧 —— **这就是标准的解耦检验 / 条件替换** |

**这一条把原本的「可分性判据」从额外难题变成了分解本身的评价指标。**

**分工**：

```
共享上游   不变 / 变化分解的【定义与划分线】
本 change  分解出的【变化分量】怎么学成该角色的运动先验 / 风格
另一个     分解出的【不变分量】怎么跨动态 / 跨视角不漂
```

- **本轮（最新）新增的六块内容**（此前只存在于对话中，现已全部落进契约）：
  1. **长时保持**：为什么隐式方法长时更容易跑出先验，以及五条解法
  2. **典型性修正**：隐式打分不能用原始似然
  3. **漂移速率**：监控 $\frac{d}{dt}(-\log p)$ 而不是水平
  4. **逐角色条件框架**：$p_p\propto p_{shared}\cdot r_p$；$r_p$ 的三来源 × 三插入点
  5. **条件 → 点**的三项公式：音频项 / 情绪区域项 / 先验正则项
  6. **character specific 的六个面** + **"路径分布薄 vs 转移统计厚"**的修正 + **条件输入必须是运动而非外观**
- **关键口径**：
  - **DC29** 对象是逐角色运动先验 $p(\alpha)$，**流形是它的水平集（解释，非实现）**；判定 = 密度分位，越界量 = $-\log p$，投影 = 沿 $\nabla\log p$ 上升，约束强度 = 引导权重 $w$
  - **DC30** A1 锚帧库**本质是非参数密度估计** → 升级路而非重启
  - **运动侧没有角色条件**是漂移的**架构级根因**（见下）
- **研究对象必须限定**：**Ditto（265D，LivePortrait renderer）与 Avatar Forcing（$\alpha$ 20D → $r=B\alpha$ 512D）是两个不同的动作潜空间**——本文研究 **FLOAT 那类 20 维正交基潜空间**。
- **已有第一手证据**：
  - **架构**：Motion Latent AutoEncoder 是**独立模块**；$\alpha\in\mathbb{R}^{20}$、$B\in\mathbb{R}^{512\times20}$ 为 **QR 正交方向基**、$r=B\alpha$；$z=s+r$；**20 维窄通道有意用来减少身份泄漏**
  - **运动侧的条件入口**（`论文笔记/float.md`）：Flow 吃 **音频 $a$、情绪标签 $w_e$、源运动 latent $w_{r\to S}$、流时间步**；**身份 $s$ 只进 decoder** → **运动分布天生"角色无关"**
  - **音频只约束一部分自由度**：口型"近乎一一对应的强条件"；**眼 / 眉 / 鼻 / 头姿"几乎与音频无关"**（`Live Speech Portraits` 原文：这些部件"sampled from the training set"）
  - **低维证据**：GT-alpha 重建 **132,726 帧**，困难音素组嘴部 L1 只高 **1.4%**
  - **非线性证据**：线性 probe 在 GT `r_d` 上 macro-F1 = **.016**
  - **运动漂移**（漂的是**运动隐变量 $r_d$ 的方向**；CSIM 是身份度量上的**读数**，其分量归属未分离）：模长假说被否证、方向游走 **+2.1°/min**、A1 CSIM **0.645→0.935**（夹角钉在 2~3°，**比 GT 的 3~5° 还紧**）；LAF CSIM `.728 > A1 .665` 但**头抖**（motion flow `.043 > GT .022`）
  - **静音更容易漂**（缺强条件）
  - **训练期参考条件化**：v1 干净 FAIL（训练库含答案，换库输出差 `<0.001`）；v2 归档失败（`sync_c` **5.342 vs 6.437**）
  - **特化必须受约束**：`全开放桥 5.719→4.565`、`桥内 LoRA 5.483 仍不如纯桥`、**注入点比 rank 更影响结果**
  - **Ditto 表示**：265 维 = scale(1)+pitch/yaw/roll(66×3)+translation(3)+expression(63)，**不含 kp**
- **三条统一（必须写出）**：
  1. **身份漂移 = 解耦不完全的泄漏量**（+2.1°/min 与新方向共用同一套测量）
  2. **模长恒定 + 方向游走 + A1 方向字典有效 → 安全域呈方向性约束**
  3. **漂移证据本身就是轨迹量**（+2.1°/min 是速率；LAF 是**点级赢、轨迹级输**）
  4. **（本轮新增）运动侧没有角色条件 → 逐角色分布拿不到，也正是漂移的架构级根因**
- **撞车边界**：**LES-Talker**（线性情绪空间，数据集级 $\mu_D,\sigma_D$）、**EDTalk++**（四空间正交基+基库）、**PSM**（逐人/通用，只刻画不生成）、跨身份重演谱系、**`Live Speech Portraits`**（2021，manifold projection 到目标人 speech space，**但在音频输入侧**）。**只剩一格**：*动作隐变量**输出侧**的逐角色先验 + 轨迹 + 引导 → 治漂移*
- **方法侧**："建低维流形 + 当先验 + 投影回去"是图形学 2004–2015 成熟手法（Grochow 2004；`Learning motion manifolds with CAE` 2015 原话就是"把无效动作投影回流形以消除误差"）；**逐个体表情流形** 2004 CVPR 已有。**贡献不能是"我们用流形/高斯"。**
- **密度与隐式侧**（本轮核实的文献）：
  - **低维线性流形 = 协方差低秩的高斯**；**RBIG 迭代高斯化**（Laparra 等 2011, cites=123）非参・可逆・处处可估
  - **density 不是可靠的 OOD 检测器**：`Do Deep Generative Models Know What They Don't Know?`（Nalisnick 等, **ICLR 2019**, arXiv 1810.09136）——flow / VAE / PixelCNN 全都如此 → **隐式打分在远处会失效**；修正见 `Detecting OOD Inputs … Using a Test for Typicality`（2019, cites=61）
  - **前向不变性**：`Control Barrier Function Based Quadratic Programs`（Ames 等, *IEEE TAC* 2016, **cites=2442**）——"安全条件以**集合的前向不变性**表述" → 正是"长时不跑出"的严格形式

### 逐角色条件框架（**隐式表示** 的核心产出）

**形式**：把"通用"改成"逐角色"，就是**乘一个逐角色权重**

$$p_p(\alpha)\;=\;\frac{1}{Z_p}\,p_{shared}(\alpha)\cdot r_p(\alpha),\qquad
r_p(\alpha_{1:T})=\underbrace{\prod_t r_p^{occ}(\alpha_t)}_{\text{做不做、做多大}}\cdot\underbrace{\prod_t r_p^{dyn}(\alpha_{t+1}\mid\alpha_t,\text{audio}_t)}_{\text{怎么动、什么节奏}}$$

**轴一 · $r_p$ 从哪来**

| 来源 | 形式 | 训练成本 | 精度 |
|------|------|---------|------|
| **非参数**（锚帧库 / KDE） | $\sum_i k(\alpha-\alpha_i^{(p)})$ | **零**（已有锚帧库） | 粗糙 |
| **参数**（每人一个小模型） | $p_{\phi_p}(\alpha)/p_{shared}(\alpha)$ | 小（20 维、几千帧） | 准、**可微** |
| **条件化**（共享模型 + 条件） | $p(\alpha\mid c_p)/p_{shared}(\alpha)$ | 中（需多角色语料） | 泛化最好 |

**轴二 · 在哪一步乘**

| 插入点 | 怎么做 | 要训练吗 | 效果 |
|-------|-------|---------|------|
| **采样时**（SMC 重加权） | 权重就是 $r_p$，按权重重采样 | ❌ | **整条轨迹有界** |
| **去噪每步**（引导） | $\nabla\log p_{shared}+w\nabla\log r_p$ | 需 $r_p$ 可微 | 闭环、平滑、强度可调 |
| **训练时**（条件化 / 微调） | 给 Flow 加条件入口 | ✅ | **修根因** |

**⚠ 条件输入必须是【运动】而不是【外观】**（本轮否掉了"单图摊销"）：

```
✘ 错：单图 → s（外观）→ p(α | s)      外观给不了运动习惯（面 3/5）
✔ 对：该角色一小段运动 {α_t} → c_p → p(α | c_p)
       c_p 可由少样本拟合（GMM / 小 flow），或 test-time 优化 c_p
```

**给 Flow 加条件的三条具体做法**：C1 条件向量（$c_p$ 拼进 $\mathbf c_t$ / AdaLN 调制）· C2 少样本嵌入（**输入运动，不是外观**）· C3 基拆分 $B=[B_{shared}\mid B_p]$（最贴近 $r=B\alpha$，$B_p$ 低秩）。

**⚠ v1/v2 的教训**：v1/v2 是**逐帧注入参考帧**（生成层）→ 泄露答案；本轮是**分布层条件 + 逐角色权重来自真实数据**。**硬约束：$r_p$ 的构造不得包含目标帧**（v1 的 `<0.001` 是铁证）。

**⚠ 工程成本**：块因果 + KV cache 的流式生成里，**粒子重采样要分支/重置 cache** —— 这是 SMC 在这套管线里最实的代价。

### 条件 → 点：三项公式（**隐式表示** 必须写）

**先纠正提法**：音频**不能**唯一确定一个点——**它只约束一部分自由度**：

| 自由度 | 与音频的关系 |
|-------|------------|
| **口型** | 近乎一一对应的**强条件** |
| **眼 / 眉 / 鼻 / 头姿** | **几乎无关**（LSP 原文：这些部件"sampled from the training set"） |

$$\alpha^\star=\arg\max_\alpha\;\underbrace{\log p(\alpha\mid a)}_{\text{音频：数据/条件项}}+\underbrace{\log p_p(\alpha)}_{\text{逐角色：先验正则项}}+\underbrace{\log\mathbb 1[\alpha\in\mathbb E_e]}_{\text{情绪：区域约束项}}$$

| 输入 | 是哪种项 | 性质 |
|------|---------|------|
| **音频** | 数据 / 条件项 | **连续**；对唇强，对头眼眉几乎为零 |
| **情绪标签** | 区域约束项 | **离散**；语义明确，但**需先定位 $\mathbb E_e$** |
| **逐角色先验** | 先验正则项 | **补上音频给不出的那部分信息** ★ |

**三种"找点"算法**：有采样器 → **引导采样**（闭环）；只有打分 → **重排 / 拒绝**（$K$ 候选，零梯度零训练）；有正向模型 → **显式 MAP 优化**（先验项即正则项）。**不建议纯 MAP**（真实动作随机，确定性求点丢自然度）。

**可证伪预测**：静音段 $\log p(\alpha\mid a)\approx 0$ → **逐角色先验的收益在静音段应显著大于说话段**。

### 长时保持：为什么隐式更尖锐 + 五条解法（**隐式表示** 与 **使用** 各写一半）

**三条原因**：① **分数在远处失效**（density 不是可靠 OOD 检测器，Nalisnick ICLR 2019）→ 梯度指不出回去的方向；② **没有"最近合法点"这个全局对象**（显式有投影）；③ **开环必然累积**（自回归把过去误差当输入）。

**公平地说**：**根因是"闭环缺失"，不是显式/隐式**。显式只在末尾投影一样会累积。

| | 解法 | 给什么 | 代价 |
|---|------|-------|------|
| ① | **闭环**：把打分放进每一步 | 误差**有界** | 每步多一次打分 |
| ② | **外部锚**：回拉目标取自**真实视频**的 $\alpha$，不是模型自己的分数 | 解**循环依赖** + 有界漂移 | 存锚点集（已有） |
| ③ | **SMC / 粒子重采样** ★ | **整条轨迹**上的正确性（权重 = $r_p$） | $K$ 路线、cache 分支 |
| ④ | **控制屏障函数（CBF）** ★ | **前向不变性保证**：$h=s(\alpha)-\tau$，要求 $\dot h+\alpha_{\text{class}}(h)\ge 0$ | 需 $h$ 平滑假设（近似保证） |
| ⑤ | **越界预算**：累计越界超预算就硬回拉 | 工程上最简的"保证" | 粗糙、有拐点 |

**分数本身也要改**：用**典型性检验**（typical set）而不是原始似然 —— 后者在远处可能反而给高分。

### 显式与隐式的关系

- **两条都保留、都报**：显式（PPCA / 椭球 / SVDD / 凸包 / KDE）作**基线**，隐式（模型打分）作**主线**
- **工程现实**：你们手上是 Flow 模型，不是一套"拟合几何"的流水线 → 隐式改动更小
- **可分诊断**：报"是 $p_{shared}$ 不准，还是 $r_p$ 不准"
