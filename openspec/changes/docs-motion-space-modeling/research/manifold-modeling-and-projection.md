## 1 结论速览

| 问题 | 答案 |
|------|------|
| 有没有"建模低维流形"的成熟方法？ | **有，20+ 年成熟方法族**（详见第 3 节），**不需要发明方法** |
| 有没有"把流形当先验 + 把无效动作投影回去"？ | **有**——人体动作领域 2015 年就做了（`Learning motion manifolds with convolutional autoencoders`） |
| "逐个体的表情/动作流形"是不是新的？ | **不是**——2004 年 CVPR 已有 `Manifold of facial expression`（且明确是**逐个体**） |
| 数字人侧有"逐角色空间 + 投影"吗？ | **有，但在音频输入侧**（`Live Speech Portraits` 2021） |
| 那还剩什么？ | **动作隐变量【输出侧】的有效区域 + 轨迹先验 + 投影 → 治身份漂移**（本轮未找到） |
| 有无“用高斯逼近流形”的现成办法？ | **有，而且是恒等关系**——低维线性流形 = 协方差低秩的高斯；迭代高斯化（**RBIG**, cites=123）可把任意分布逼近到高斯，且非参・可逆・处处可估 |
| 轨迹怎么建模？ | 用**同一套“高斯”语言**：**GP / GPDM**（cites=1049）· 线性高斯状态空间 · **逐角色自回归概率模型**（LSP 已做）。⚠ **统计上薄：一段视频只给一条路径** |
| 结论 | **贡献不能是“我们用流形/高斯”，只能是那三步的组合 + 把漂移重述为点级+轨迹级的几何量** |

## 2 四个必读

### 2.1 `Style-based Inverse Kinematics`

- **出处**：Grochow, Martin, Hertzmann, Popović，*ACM Transactions on Graphics* **2004**，DOI `10.1145/1015706.1015755`，**cites=648**
- **原话（摘要）**：「模型表示为**姿态空间上的一个概率分布**。这意味着我们的 IK 系统**能生成任意姿态，但偏好最接近训练数据姿态空间的那些姿态**」，实时求解；「**在不同输入数据上训练会得到不同风格的 IK**」
- **模型**：**Scaled Gaussian Process Latent Variable Model (SGPLVM)**
- **为什么必读**：一件事同时命中三点——
  1. **低维流形建模**（SGPLVM）
  2. **用它约束生成**（求解时偏向高概率区域）= 你们的"投影 / 夹紧"
  3. **逐角色**（"different styles" = 不同训练数据 → 不同空间）——**逐角色特化在 2004 年就有原型**

### 2.2 `Learning motion manifolds with convolutional autoencoders` ★ 最接近"库 + 投影"

- **出处**：Holden 等，**2015**，DOI `10.1145/2820903.2820918`，**cites=274**
- **原话（摘要）**：「把该流形视为**动作数据的先验概率分布**，在动画研究中有多种应用，包括：**把无效或损坏的动作投影到流形上以消除误差**、用**沿流形的测地距离**计算动作相似度、**沿流形插值**以避免混合伪影」
- **为什么必读**：**你们的身份漂移治理 = 把"损坏的动作投影回流形"**，在人体动作上已有原型与措辞可直接借用

### 2.3 `Manifold of facial expression` / `Probabilistic expression analysis on manifolds`

- **出处**：Chang, Hu, Turk 等，**2004**（DOI `10.1109/amfg.2003.1240820`，**cites=122**）与 **CVPR 2004**（DOI `10.1109/cvpr.2004.1315208`，**cites=123**）
- **原话**：「图像序列中**一个个体**的所有可能面部形变，在特征空间构成一个**光滑流形**」（用 **LLE + Lipschitz 嵌入**学习）；「一段完整表达序列成为流形上一条**从中心出发的路径**」
- **为什么必读**：两点——
  1. **明确是逐个体**的流形 → 逐角色性不是新东西
  2. **"中心 + 路径"= 你们那个"以中性点为顶点的锥"结构**，2004 年 CVPR 就是这么描述的
- 延伸：`Manifold based analysis of facial expression`（*Image and Vision Computing* 2005，**cites=218**）、`Learning Expressionlets on Spatio-temporal Manifold`（CVPR 2014，**cites=401**）

### 2.4 `Live Speech Portraits` — 数字人侧最接近（但位置不同）

- **出处**：Lu 等，*ACM Transactions on Graphics* **2021**，DOI `10.1145/3478513.3480484`，**cites=162**；arXiv [2109.10595](https://arxiv.org/abs/2109.10595)
- **原话**：「第一阶段是一个深度神经网络，提取深层音频特征并配合 **manifold projection** 把特征**投影到目标人的 speech space**」；动机是「wild audio 与 target speech space 之间的域差……使系统**无法保留个体的说话习惯（individual talking idiosyncrasies）**」
- **⚠ 读全文后的关键限定**：它是**音频特征侧（输入侧）**的投影，**不是动作隐变量输出侧**。**概念同形，位置不同。**
- **对项目的意义**：这是"逐角色空间 + 投影"在数字人侧的最近邻——**必须在 `10` 里作为直接邻居列出**，并写明差别（输入侧 vs 输出侧）

## 5 轨迹建模：把流形上的**路径**也建成先验

**为何单独讲**：流形回答“哪些点合法”，轨迹回答“哪些**走法**合法”。而你们的漂移证据**本身就是轨迹量**：

| 你们的证据 | 它其实是 |
|---|---|
| 方向游走 **+2.1°/min** | 一个**速率**（每单位时间的角度增量）→ **轨迹性质**，不是点性质 |
| Learned Anchor Force：CSIM `.728 > A1 .665` 但 **motion flow `.043 > GT .022`** | 点级身份↑、**轨迹级平滑度↓**（头抖 = 轨迹变糙） |
| 静音时更容易漂 | 缺强条件时，**轨迹自回归地累积误差** |

**所以**：A1 与 LAF 的差别不只是“约束强度”，而是**点级约束 vs 轨迹级后果**。**LAF 在点级赢了、在轨迹级输了。**

### 5.1 轨迹的建模方式（同一套“高斯”语言）

| 做法 | 形式 | 说明 / 出处 |
|------|------|-----------|
| **GP / GPDM** ★ | 对轨迹的**高斯分布** | `Gaussian Process Dynamical Models for Human Motion`（*IEEE TPAMI* 2007, **cites=1049**）：「低维隐空间 + **伴随的动力学**」，对动力学与观测映射都用 GP 先验 |
| **线性高斯状态空间 / VAR** | $\alpha_{t+1}=A\alpha_t+\epsilon$ | 最简；**白化坐标下往往够用** |
| **逐角色自回归概率模型** ★ | 从历史 + 条件采样 | **`Live Speech Portraits` 就是这么做的**：「autoregressive probabilistic model 学**目标人的头姿分布**」——逐角色轨迹先验已有先例 |
| **测地线插值** | 沿流形最短路径 | `Learning motion manifolds with CAE`（2015）用它避免混合伪影 |
| **相位 / 基元** | phase variable、motion primitives | `MMP++`（*IEEE T-RO* 2024）那条线 |
| **流匹配的向量场** | $v_t$，连续时间 ODE | **你们系统里已经有**（Flow matching 就是在学轨迹的速度场） |
| **Koopman 算子谱** | 非线性动力学 → 线性算子 | 与坐标系侧的谱签名**共用同一算子** |

### 5.2 一条必须写进设计的限制（统计不对称）

```
流形：一段视频给【很多样本点】→ 统计上厚（几千帧的 α_t）
轨迹：一段视频只给【一条路径】→ 统计上薄
```

**后果与三条出路**：
1. 从**多角色语料**学**共享动力学**，逐角色只调**节奏 / 尺度**（推荐；数据现成）
2. 从**同一人的多段视频**学（把采集要求从“一段”提到“多段”，**改成本**）
3. **轨迹层增广**：时间反转、变速、片段重组（最便宜，但只能扩部分不变性）

### 5.3 先例的呼应

2004 CVPR `Probabilistic expression analysis on manifolds` 说的是「一段表达序列成为流形上一条**从中心出发的路径**」——**路径 + 中心**，正是“**轨迹 + 锥顶点**”。

## 6 坐标系的选择：如何让空间“更好算”（高斯化及其替代）

### 6.1 关键等式

$$\mathcal{N}(\mu,\Sigma)\ \text{的支撑集}\ =\ \mu+\mathrm{range}(\Sigma)$$

若 $\mathrm{rank}(\Sigma)=k<20$，支撑集就是一个 $k$ 维仿射子空间。**PPCA 把它写成显式模型**：$x=Wz+\mu+\varepsilon$，$W\in\mathbb{R}^{20\times k}$、$\varepsilon\sim\mathcal{N}(0,\sigma^2 I)$。

> **低维线性流形 = 协方差低秩的高斯。**

### 6.2 三档“高斯逼近”

| 层次 | 做什么 | 方法 | 被引 |
|------|-------|------|------|
| ① 线性高斯 | 只对齐一二阶矩 | PCA / **PPCA** / 因子分析 | 1909 |
| ② **迭代高斯化** ★ | 找可逆 $T$ 使 $T(\alpha)\to\mathcal{N}(0,I)$ | **RBIG**（Laparra 等, *IEEE TNN* 2011, DOI `10.1109/tnn.2011.2106511`）：反复「逐维边缘高斯化 + 正交旋转」；**非参・可逆・处处可估**；2022 有 Convolutional RBIG | **123** |
| ③ 层次高斯化 | 多峰时用高斯混合 | GMM / **Hierarchical Gaussianization**（ICCV 2009, DOI `10.1109/iccv.2009.5459435`） | 145 |

高斯化后的“有效区域”变成小球：$\{\alpha:\|T(\alpha)\|\le r\}$ → **判定闭式、投影闭式、文件里只存 $T$ 的参数**。

### 6.3 除高斯化之外的替代（按“替换掉哪一层”分）

| 替代 | 把什么换成什么 | 优点 | 代价 |
|------|--------------|------|------|
| **均匀化 / Copula** ★ | 边缘 → 均匀，再单独建**依赖结构** | 有效区变**盒子** $[0,1]^k$，比球更简单；copula 提供“纯形状”的可比对象 | 需估边缘 CDF；高维需 vine 分解 |
| **ICA** | 换成**独立**（非高斯）成分 | 方向更可解释 | 只能去二阶+独立，未必简化区域 |
| **白化** | 只去二阶相关 | 最便宜（就是 PCA） | 曲率与多峰全留下 |
| **字典学习 / 稀疏编码** ★ | 点 → **少量原子的稀疏组合** | **坐标有语义**（哪个原子 = 哪块形变）；稀疏 = 低维；残差 = 离流形量 | 判定/投影要多解一步 $\ell_1$ |
| **谱签名（Laplacian / 热核）** | 用**谱**表示流形本身 | **紧凑、跨角色可直接比** | 只给签名，不给区域 |
| **TDA / 持续同调** | 用**拓扑**表示 | 诊断多峰/拓扑极强 | 只作诊断 |
| **Koopman 算子** ★ | 非线性动力学 → 线性算子，用**谱**表示 | 空间与轨迹**共用**一个算子 | 需选可观测量字典 |
| **SDF / 隐式神经表示** | 流形 → **零水平集** | 不假设拓扑 | 黑箱、投影要梯度步 |
| **凸包 / 多面体** | 支撑集 → 凸多面体 | 判定 = LP、投影 = QP | **20 维不可行**（面数爆炸）；只在降到低 $k$ 后可用 |

### 6.4 三条判断

1. **高斯化好算但坐标无语义；字典/稀疏编码坐标有语义但要多解一步。两者可以叠**：先用字典拿到**语义原子**，再对**原子系数**做高斯化。
2. **高斯化会把“每人独特”抹平**（LES 的 $\mu_D,\sigma_D$ 陷阱的另一种形式）→ 独特性搬到 **$T_p$** 或**谱签名**上，它们提供**公共参照系**，把“每人独特”从“比较绝对位置/尺度”变成“比较**形状**”（同统计形状模型的“先对齐再比较”）。
3. **残余的非高斯部分不是噪声，是信号**——角域约束（你们的锥）、多峰、偏度，正是承载身份与行为语义的结构。

### 6.5 与你们现有架构的接口

$r=B\alpha$ 里 **$B$ 本身就是一部字典**（正交、20 个原子）→“字典/稀疏”族是**最低边际成本**的扩展（放宽正交 → 冗余字典 → 稀疏码）；高斯化则是**改坐标**。两者不改同一层，可叠。

```
      ① 有效维数 k 是多少            → "低维流形"到底有多低

      k 小且残差小        →  族 1 单一线性子空间（最简）

      要更紧的边界        →  族 3 SVDD（球 / 椭球）
      要更强表达力        →  族 4 GPLVM / 族 7 SDF

叠加角度约束：你们证据是「模长恒定 + 方向游走」
      →  判定与投影都要在球面 / 角域上做，不能只用轴对齐的盒子

```

## 10 一句话版

> **“建模低维流形 + 把它当先验 + 把无效动作投影回去”是图形学 2004–2015 的成熟手法；“逐个体的面部表情流形”2004 年 CVPR 就有；数字人侧的“逐角色空间 + 投影”也已存在但落在【音频输入侧】。本项目剩下的位置是：把这件事搬到【运动隐变量的输出侧】，用来治【身份漂移】，并把漂移重述为可度量的几何量（点级 + 轨迹级）。**
>
> **补两个关键点**：① **轨迹和流形要分开建模**，而且你们已有的漂移证据（+2.1°/min、LAF 的 motion flow）**本身就是轨迹量**；② **“低维线性流形 = 低维高斯”是恒等关系**，所以坐标高斯化（RBIG）是一个合法且便宜的表示选择——但它**会把“每人独特”抹平**，独特性必须显式搬到 $T_p$ / 谱签名上。
