## 4. 第三部分：我们对潜动作空间数字人模型的理解（新写）

**一条链**：它是什么 → 靠什么成立 → 三个软肋 → 由软肋推出的判断；全章只回答一个问题。

- [ ] 4.1 3.1 **它是什么：两级结构**（低维运动生成 + 渲染器）；三个好处（实时/可控/身份复用）与两个代价（画面靠参考搬运、工作单元是裁剪脸框 ⇒ 只解脸）。
- [ ] 4.2 3.2 **它成立的前提是"身份与运动可分解"**；并把"身份=不变部分、风格=变化部分"作为**这类模型的工作假设**引入；**补三式对照表**（隐空间加法 $z=z_S+m_S$ / LivePortrait 式 $x=s(x_cR+\delta)+t$ / PerformRecast 式 $x=s((x_c+\delta)R)+t$），点明"可分解"还有第三个维度：**两项以什么方式组合**。
- [ ] 4.3 3.3 **软肋一：解耦只是近似** —— 用实测反例（身份项恒等但方向 +2.1°/min 游走）引出 **★分界线不是先验给定的**（三个判不清的例子 + 区分"先验给定"与"从数据学"两种做法 + 三条分解判据）。
- [ ] 4.4 3.4 **软肋二：动作是分布不是点** —— 建模对象是逐角色先验 $p(\alpha)$，流形 = 水平集；可打分/可投影/可采样；越界量 $-\log p$；**锚帧库 = 非参数密度估计 ⇒ 升级非重启**。
- [ ] 4.5 3.5 **软肋三：条件只给一半自由度** —— 后验采样 $p(\alpha\mid a)\propto p(a\mid\alpha)p_p(\alpha)$；**情绪是区域约束项、音频是数据/条件项（不同类）**；并点出本范式边界（条件给不全 → 先验补 → 回到分界线问题）。
