## Context

`management/docs/论文笔记/avatar-forcing.md` 当前 340 行、11 个二级节。论文侧的“生成结果如何成为下一段历史”写在 [推理与系统链路]（offset + rolling KV cache），我们自己的长期实验与治理裁决则压缩在 `## 局限与启发` 下的 `### 我们的实测` 两条 bullet 里。两处相距约 90 行，读者无法把“递归历史”与“方向游走、静音更严重、A1 引导有效”连成一条诊断链。

可用的量化证据来自 `knowledge/Avatar Forcing 微调实践.md`：c1 单身份 300 秒轨迹上，noguide 的 motion latent 与首帧夹角 10.1° → 15.1° → 17.5°（+2.1°/min），模长三段 2.03 / 2.04 / 2.01；A1 锚点引导把方向维持在 2–3° 并把该单例 CSIM 从 0.645 提到 0.935。

### 落点理由

新小节放在 `### 论文自己承认的局限` 之后，理由有三：

1. **承接关系顺**：论文承认“Diffusion forcing 并未完全解决 exposure bias”，紧接着就是我们把它变成可检验诊断，读者不需要在两节之间来回跳。
2. **归属正确**：这是我们对论文留白的实测，不是论文的方法或结果，因此留在 `## 局限与启发` 内，不提升为与 `## 实验与结果` 并列的二级节——那会让人误以为它是本文的实验章节。
3. **长度可控**：诊断（机制 + 假说 + 表 + 静音）约 700–900 字；治理与适配的完整实验史（v1/v2、LAF、CSIM-as-loss、桥系列）继续留在 `knowledge/Avatar Forcing 微调实践.md`，本笔记只保留裁决结论。

**备选方案（未采用）**：把漂移提升为 `## 长时身份漂移诊断` 独立二级节，插在 `## 实验与结果` 与 `## 相关工作与定位` 之间。否决原因是它会把“论文笔记”正文切出一条我们自己的实验线，且与 `## 实验与结果` 的论文口径混淆；同时 `## 局限与启发` 会只剩论文局限与启发三条，结构头重脚轻。

### 为什么把原 `### 我们的实测` 拆成两段

原文一条 bullet 同时承担“漂移诊断”与“治理裁决”两件事，粒度不对等：诊断部分要讲机制、假说、实验与边界，治理部分是四项裁决的清单。拆开之后：

- 新小节回答 **“为什么漂、漂什么”**；
- `### 我们的实测：治理与适配` 回答 **“我们试了什么、怎么裁决”**，并在开头一句指向新小节，避免“漂移诊断”重复出现两次。

## Decisions

### D1：新增小节 + 拆分“我们的实测”，而不是继续加长 bullet

按上文落点方案执行。备选方案是在现有两条 bullet 后补数字，否决原因是历史传递、两个假说、证据边界与静音条件会继续被压平，回答不了“为什么漂、漂什么”。

### D2：把历史递归写成机制解释，不夸大为已证实的唯一根因

复用文中已披露事实（下一 block 用上一 block 末 `l` 帧 offset、rolling KV cache 复用历史、推理期不重读身份锚帧），再解释：每段小误差会被当成下一段的真实历史，形成开放环；固定 $z_S$ 只固定 identity latent，近似解耦下不保证 $z_S+r$ 解码出的身份恒定。

措辞用“构成开放环风险”“与观察到的方向游走一致”，不写“已证明所有漂移由 offset 导致”——当前没有 offset/KV 的因果消融。

### D3：模长与方向成对呈现，表格并列两项实验

定义逐帧运动 latent $r_d$ 的模长与相对初始方向的夹角：

$$
\theta_t = \arccos\!\left(\frac{r_t \cdot r_0}{\lVert r_t \rVert_2 \, \lVert r_0 \rVert_2}\right)
$$

| 假说 | 观测对象 | c1 / 300 秒结果 | 裁决 |
|---|---|---|---|
| 范数撑开 | $\lVert r_d\rVert_2$ 是否持续增大 | noguide 2.03 → 2.04 → 2.01（-0.01/min）；GT 与 A1 近水平 | 不支持 |
| 方向游走 | 与首帧夹角、到 GT 方向字典距离 | noguide 10.1° → 15.1° → 17.5°（+2.1°/min），最近邻峰值 24.8° | 单身份支持 |

表后补 A1 对照（3.4° → 3.3° → 2.5°，峰值 6.2°），并声明“支持优先约束方向，不是跨身份默认策略”。

### D4：静音放大单列一段，并显式标注证据等级

说明说话时 avatar audio 逐帧约束口型与节奏，静音时该强约束变弱、倾听表情与微头动本是多解，生成器更依赖递归历史，因此我们在长静音片段观察到更明显漂移。段末标注：这是“工程观察 + 与条件结构一致的机制解释”，尚缺固定身份、参考图、随机性与总时长的静音/非静音配对对照。

### D5：治理只保留与诊断相连的结论

本节只简述 A1（依据是“问题在方向”）：c1 单例 300 秒 CSIM 0.645 → 0.935、后半段塌方消失、未观察到唇同步下降。训练期条件化 v1/v2、Learned Anchor Force、CSIM-as-loss 的完整失败史不外链展开，压缩结论保留在 `### 我们的实测：治理与适配`。

### D6：小节标题不含冒号

标题定为 `### 长时身份漂移：历史递归、方向游走与静音放大`——注意文档锚点 slug 会吃掉冒号，因此锚点写作 `#长时身份漂移历史递归方向游走与静音放大`。实施时先渲染确认锚点可用，再写跨节链接。

## Risks / Trade-offs

- [把静音观察写成普适定律] → 显式标注观察性质与缺失的配对消融，限定为当前资产与运行路径。
- [把方向相关性写成唯一根因] → 用“支持假说”“与递归误差一致”，并声明未做 offset/KV 因果消融。
- [数字与知识文档不一致] → 复用已核对的 c1 三段模长表、夹角表与 A1 数值；实施前以 `Avatar Forcing 微调实践.md` 逐项复核。
- [内容重复] → 漂移诊断只在新小节出现一次；原“我们的实测”删去该 bullet 并改为指向链接。
- [锚点 slug 不稳] → 标题不用冒号、不用会被吃掉的长标点；实施后在文档页实际点击验证两个新增链接。
- [拆分小节导致 `局限与启发` 变长] → 治理与适配维持 bullet 压缩形态，完整实验史留在 knowledge 篇。
