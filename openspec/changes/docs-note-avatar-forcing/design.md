## 【待审核】正文大纲（5 节）

### 一、`## 是什么`

- 论文信息：标题、机构、年份、一句话定位（**一步式流式说话头像**：用局部未来滑动窗口去噪，把"一次生成一小段 + 立即渲染"做成一步生成）、arXiv 条目与年份
- 它在文献里的位置：属于"动作空间 + 快速渲染器"路线的交互式分支，面向**双向对话**（既生成说话，也生成倾听）
- 一句话读完的版本：**把身份与运动显式分解，把条件分两路编码，把生成为按块向前滚**

### 二、`## 架构核心`

- **链路**：驱动信号（用户音频/视频 + 待说音频）→ 表示（身份项 + 运动项显式分解）→ 生成（因果、按块的扩散去噪）→ 渲染（解码器出帧，身份项恒定参与）
- **三个模块**（每个写清"解决什么问题 + 关键取舍"）：
  1. **运动潜空间编码**：显式 identity-motion 分解（身份项 / 运动项），身份项在整个对话中固定——**这是它"训练用视频、推理能用单图"的原因**
  2. **双路条件编码**：把"用户在做什么"与"avatar 这次要怎么说"编码成同一种条件——**这是它能出听态画面的原因**
  3. **因果流式生成**：按块向前滚动，块间用历史 offset 与缓存衔接；训练期用有限的 look-ahead 缓解边界抖动
- **运动接口的真实维度**：给渲染器的接口是 512 维，但落在最多 20 个独立方向的子空间里——**这是最容易被误读的一点**（看起来 512 个旋钮，实际 20 个）
- **与同类差异一表**：

  | 对比对象 | 表示 | 身份处理 | 生成范式 | 流式能力 |
  |---|---|---|---|---|
  | AvatarForcing | 身份项 + 20 维运动（对外 512 维接口） | 身份向量全程固定，加法解耦 | 因果扩散（按块滚动，一步生成） | 有，且支持打断/切换输入 |
  | FLOAT（同血统） | appearance + motion 显式分解 | 同上（加法解耦） | 生成式但非为交互设计 | 无原生流式 |
  | Ditto | 关键点 + 头姿/平移/表情（265 维） | 参考帧外观 + 关键点 warp | 运动空间扩散 + 快速渲染 | 有（窗口式） |
  | LivePortrait | 隐式关键点 | 参考图外观 + warp | 无扩散（直接形变） | 有（轻量） |

### 三、`## 在我们体系中的角色`（工程层）

- **接入形态与契约**：作为 avatar 插件接入，实现统一契约（设置形象 / 音频流进视频流出 / 重置 / 帧率与输出尺寸）；双向插件额外提供用户音视频输入——**契约统一是它能被替换进链路的前提**
- **流式改造**（我们做的事）：把批量生成改成连续流的 producer/consumer；首块产出后可连续出帧；接入静默运行时
- **微调**（我们做的事）：
  - **中文音频适配**：在中文音频编码器与冻结主干之间加桥（蒸馏桥 → 几何约束桥 → 关系蒸馏），主干保持冻结
  - **微调形态与注入点**：全冻结+桥 / LoRA / 单层解冻三档的实际结论（注入点比 rank 更影响结果；全开放会让桥与主干失去配合）
- **漂移诊断与治理**（我们做的事）：把漂移拆成"模长撑开"与"方向游走"两个假说 → 模长被否证、方向游走得单身份支持 → 四种治理手段的裁决（锚点引导有效；训练期条件化两轮失败；学习式锚力指标高但人眼头抖；身份相似度当损失管不住尺度漂移）
- **结论表**：每项一行——**做了什么 / 结果 / 证据强度 / 边界**

## 【待审核】决策点

1. **"参考与延伸"能不能写内部路径**：复盘正文有"不写出处"的硬规则；但笔记的用途就是索引——
   (A) 笔记允许列 **arXiv id / 论文名 / 外部链接**，**不写** `knowledge/` 内部路径（保持"内部引用只走文档链接"的一致性）**【建议】**
   (B) 笔记允许列 `knowledge/` 精读路径（作为素材索引）
   (C) 完全同复盘：不写出处（`## 参考与延伸` 只写"论文名 + 外部链接"）
2. **工程层写多深**：
   (A) 只写接入与改动结论 + 链各复盘篇 **【建议】**
   (B) 把微调与漂移的数据表也放进来（会与复盘篇重复）
3. **失败结论是否进笔记**：
   (A) 进（与复盘一致，保留负结论）**【建议】**
   (B) 不进（笔记只记"是什么/怎么接"，失败留在复盘篇）

## Decisions

- **D1 素材不落仓库**：整理结果只在对话中提交审核
- **D2 数字与结论溯源**：所有数字标注来源（复盘篇 / 精读），不新造
- **D3 不重复成篇叙事**：复盘里已经写透的内容只留结论 + 链接
- **D4 标题规范**：不用桶标题、标题不用冒号、文档间引用用 `[[slug|名]]`

## Risks / Trade-offs

- [笔记与复盘重复] → 笔记以"该模型的视角"组织（架构 → 接入 → 改动），复盘以"主题的视角"组织
- [工程层写成流水账] → 工程层只保留结论表，过程一律链过去
- [外部信息可靠性] → 论文层以论文与官方仓库为准；二手观察注明性质
