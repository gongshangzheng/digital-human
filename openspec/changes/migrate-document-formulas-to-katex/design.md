## Context

`docs-math` 已定义 `$...$`、`$$...$$`、Mermaid 中 `$$...$$`、失败降级和普通美元符号的渲染契约。初步扫描虽在 `management/docs/` 找到大量候选，但 `management/docs/knowledge/` 是后续将清理的临时归档区，明确不纳入本次审核或迁移。DPO 技术介绍和 Avatar Forcing 笔记均含多行纯文本目标函数，是本次仅有的迁移范围。

## Goals / Non-Goals

**Goals:**

- 以语义审核替代全局正则替换，只有承担定义、推导、损失、概率、集合或正式约束职责的表达才迁为 KaTeX。
- 优先使 DPO 与 Avatar Forcing 的公式在页面中以块级/行内数学呈现，且符号表、邻近解释和原有数学含义一致。
- 将旧 `\(...\)` 和 `\[...\]` 迁为支持的定界符，并保留已正确的公式。
- 输出两篇目标文档的公式审计清单，说明迁移或字面保留的理由；随后做渲染和内容验证。

**Non-Goals:**

- 不把所有反引号标记、型号、路径、金额、命令、URL、普通比较式或单词中的下划线转为数学。
- 不引入新的公式、推导、实验结果、参考文献或对论文含义的解释。
- 不修改 `management/docs/knowledge/`、renderer、KaTeX 配置、sidecar、文档阅读顺序和 archive 历史。

## Decisions

### 公式语义分级

迁移按三类执行：

| 类别 | 处理 | 例子 |
|---|---|---|
| 明确数学 | 迁为 `$...$` 或 `$$...$$` | 概率、损失、KL、范数、向量空间、矩阵、掩码、期望、优化目标 |
| 已正确的数学 | 保留并仅核查 | 现有 `$z_S$`、`$$r=B\alpha$$` |
| 非数学或代码语义 | 保持字面/代码 | `1e-4`、`512×512`、`$5`、shell 变量、路径、模型配置字段 |

块级公式用于独立的完整关系或多行目标；行内公式只用于句子中短符号或短关系。每个迁移公式必须紧邻已有的符号解释；若原文没有解释，只能补充从原文已给定含义直接得出的最小符号说明。

### DPO 优先及逐文档审阅

仅审 `技术介绍/dpo-直接偏好优化.md` 和 `论文笔记/avatar-forcing.md`。DPO 技术介绍的通用目标、KL 目标、闭式策略、隐式奖励、Bradley–Terry 概率和 DiffusionDPO 损失迁为 KaTeX；Avatar Forcing 的 latent 分解、因果分解、掩码、训练目标、DPO 目标和 offset 迁为 KaTeX。`knowledge/` 中即便出现旧定界符也不处理。

### 审计文件而不重写正文历史

变更中新增 `formula-audit.md`，仅列出两篇目标文档中的候选表达与结论（迁移或字面保留）及理由。它只记录本次审核覆盖，不能作为正文事实来源；不改 `knowledge/`、archived 文档或历史 OpenSpec artifacts。

## Risks / Trade-offs

- [把金额或代码误解析为数学] → 保留代码围栏和行内代码，验证 `$5 到 $10` 仍为字面文本。
- [迁移时改变论文公式] → 用原有文本或一手缓存逐项核对；只调整定界符和排版，不改符号、范数、权重或正负号。
- [临时归档区造成无意义 diff] → 明确排除 `management/docs/knowledge/`；仅更改两篇目标文档中确认属于数学表达的行。
- [块级公式缺符号解释] → 优先保留并引用附近解释；必要时补一句最小、可由原文直接推出的符号说明。

## Migration Plan

1. 审阅两篇目标文档中的候选表达，按语义分类。
2. 迁移 DPO 和 Avatar Forcing 的确认公式，逐项与现有文本核对。
3. 记录 audit，并扫描两篇目标文档中的不支持定界符、代码块和金额边界。
4. 以 renderer 的 KaTeX 测试、前端构建和 OpenSpec 严格验证验收。
5. 回滚时仅恢复本 change 修改的 Markdown 与 audit 文件；渲染能力不受影响。
