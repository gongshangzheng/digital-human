- 未使用 `\(...\)`、`\[...\]` 或 `\begin{equation}` 等当前渲染器不支持的数学定界符（Avatar Forcing 公式内部的 `\begin{cases}` 是 KaTeX 块级公式的环境，不是 Markdown 数学定界符）。
- 本次不修改渲染器、依赖、后端接口、sidecar、文档顺序或归档 OpenSpec 历史。
- 迁移只调整数学排版与必要的相邻符号形式；不改符号、正负号、范数、权重、引用、实验主张或论文专属解释。
