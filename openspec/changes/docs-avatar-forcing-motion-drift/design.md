## Context

实测事实（`论文笔记/avatar-forcing`）：漂移发生在**逐帧运动隐变量 $r_d$ 的方向**上（+2.1°/min，模长恒定）；推理期锚点引导**约束的是这个方向**，使 CSIM 由 0.645 回到 0.935。

被质疑的归因：笔记里把根因写成"加法解耦只是近似、运动项渗透进外观"。这是**我们的推断**，论文只说过"没有表示能保证完全解耦"这句泛论；且有一个同样自洽的替代解释——**漂的本来就是动作**（头姿/表情缓慢偏移 → 侧脸变多），而现有身份度量**对姿态/视角敏感**，于是度量读数自然下降。

**结论**：现象应写成**运动输出漂移**；"它是否导致身份/外观变化"是需要实验分离的问题（姿态对齐后再测 CSIM / 分置实验 / 交换检验 / 人眼+尺度）。

## Goals / Non-Goals

**Goals：** 把"身份漂移"这一口径在库内统一改成"运动输出漂移"；补上"分量归属未分离"的限定；标题改名后同步锚点。

**Non-Goals：** 不改实测数字与结论；不改归档 change；不改外部知识快照的正文（只加 scope note）；不改其他论文自己的术语（liveact 图 5、OmniMate 的问题陈述）。
