## Why

> **新命题**：**如何从【一个视频 / 多段视频 / 多视角照片】中学出角色的【身份】，并让这个身份在【多种动态】（表情、姿态、视角、机位、风格）下保持一致。**

这是与 `docs-motion-space-modeling`（学*怎么动*）并列的另一半：那个 change 解决**运动先验 / 风格**，这个 change 解决**身份**。

**它在本仓库已有分散记载，但没有统一的问题陈述**（这正是本 change 的第一个产出）：

| 分散在哪 | 关键句 |
|---------|-------|
| `数字人领域问题` §一 → `### 多参考注入：从一张图到任意多角度` | "多参考的目标不是把更多图片堆进条件，而是把**数量不定、位姿未知、质量不一**的图像聚合成稳定身份表示"；"多参考能改善'看不到的角度怎么办'，**不能自动解决'所有角度是否是同一人'**" |
| `数字人领域问题` §一 → `### 切分镜与多视角：换机位之后还是不是同一个人` | "**跨机位一致性还没有形成普遍协议**" |
| `数字人领域问题` §一 → `### 身份一致性判别器` | 要求输出**三个通道**（身份一致性 / 质量可信度 / 时序漂移量），并列出"哪些变化不该扣分" |
| `数字人领域问题` §五 → `缺失、噪声与冲突条件鲁棒性` / `条件化任务的可比评测` | "单图冷启动、任意多张无位姿参考、多视角参考与专人训练资产提供的**身份信息量不同**" |
| `数字人领域问题` §四 → `路线五：3D 资产` | "**资产化并不自动保证跨视角正确**"；单图/少图重建的背面与遮挡区缺少观测 |

**并且要划清与另一半的边界**：`数字人领域问题` §一 `### 说话风格` 明确指出 —— **"身份回答'是谁'，风格回答'这个人怎样说话、怎样动'。两者容易纠缠"**（某些嘴形、点头频率、眉眼运动**既可能被误当身份，也可能来自说话习惯**）。**这条纠缠是本 change 必须处理的第一个问题**，否则两个 change 会互相污染。

## What Changes

- 新增 **调研记录**（`research/`）：多视角/视频身份学习的方法与撞车边界
- 新增 **问题的统一定义**：把上述分散记载合成一个可研究的问题陈述（含边界：身份 vs 风格）
- 确定**落点与文章结构**（是否与 `动作空间建模` 并列建 `身份建模/`，篇数多少）
- 不改动既有文档正文、代码与接口
