## 2. 补读摘要要点（11 篇，一手）

### DSFD（`2609.10317`）——对本仓库最重要的一篇

- **核心论证**：视频 latent 被身份 / 外观 / 背景占据，音频与这三者都无关——**把音频逐像素耦合进视频扩散模型会糊掉细节、浪费容量**。
- **做法**：条件融合挪进**低维身份解耦运动空间**；音频与运动 caption 按**时间粒度分流**；小因果自回归 transformer 生成运动 latent，**预训练**扩散渲染器出视频；"条件间接控制视频，高保真不再需要大主干"。
- **与 Causal Forcing 的关系**：指出**运动空间里没有双向教师**可蒸馏（CF 的批评只覆盖像素空间），提出 decoupled self-forcing 解 exposure bias。
- **与本仓库的映射**：③ 两级结构"算力花在 20/265 维而不是像素上"的**论文级佐证**；同时它也没做显式控制接口（用 motion captions 而非关键点/系数指令）——"仍然空着"第一条依然成立。

### Q-ARVD（`2605.21072`）

- 把标准 DiT 量化方案直接用于自回归视频扩散（ARVD）会次优；两个挑战：**C1** AR 误差累积导致逐帧量化敏感度**指数式衰减的不均衡**；**C2** 权重离群通道模式随层类型与深度显著异变。
- 映射：C1 是 **AR 误差累积的量化侧证据**，与我们长时漂移（历史递归）同源——"误差沿生成链复利"在不同层（量化/运动方向）重复出现。

### InterDyad（`2603.23132`）

- Interactivity Injector：从参考视频提**身份无关运动先验**做重演；MetaQuery + MLLM 从音频**蒸馏语言意图**、决定反应的时机与恰当性；RoDG（角色感知双人高斯引导）解**极端头姿下唇同步**；配套双人交互评测套件。
- 映射：MLLM 定反应时机 ≈ 我们"打断止声正确性由人眼与听感决定"的对偶（何时说 vs 何时停）。

### ECHO（`2603.17427`）

- 指出现有交互头像生成的两个病：**短窗双轨信号缺长程上下文**（行为不合语境）与**角色不分的融合**（说话时跨信号干扰唇区同步）；LCU 组件补长程语境理解。
- 映射：角色不分融合 ⇔ 我们方法论"**条件注入要按类处理**"——外部佐证。

### Listener Nodding（`2607.12329`）

- 把听者动作细化到**点头**这一个动作：基于 VAP（Voice Activity Projection）的双人注意力网络，**同时预测点头时机与运动学参数**；从时机预测模块初始化运动学模块的微调有效；轻量实时。
- 映射：与 GDPO-Listener 互补——一个治"塌成静态脸"（偏好优化），一个把单一动作做成**显式参数预测**。

### MindFlow（`2606.27779`，本轮新发现）

- 神经科学腹背双通路：**Ventral** 把 Sentence-Action 换成 **Chunk-State 情绪状态链**（捕捉句中情绪转折与副语言细节）；**Dorsal** 条件自回归流匹配出面部运动 + **Selective Acoustic Injector** 在说/听动态中自适应门控音频。
- 映射：Chunk-State ≈ 情绪作为**区域约束/状态**而非逐帧标签（与领域问题 §二"情绪是区域约束项"同向）；声学门控又一条"条件按类处理"证据。

### CausalCine（`2605.12496`）

- 多镜头叙事的因果生成：原生多镜头序列训因果底模型；**CAMR** 按注意力相关度（而非时间邻近）检索历史 KV，有界显存下保跨镜头一致；动态 prompt 在线导演。
- 映射：CAMR 与我们锚帧库同属"**该信什么要显式选择**"；跨镜头一致性是"切分镜"问题的流式版。

### LPM 1.0（`2604.07823`）

- 提出 **performance trilemma**：表现力 / 实时 / 长时身份稳定三者难兼得；17B DiT 基座（多模态条件、identity-consistent）蒸馏出因果流式 Online LPM；全双工会话表演；**identity-aware 多参考抽取**。
- 映射：trilemma 与我们"四个固有限制 + 实时工程线"同构；多参考抽取直接接 §一「多参考注入」★。

### Wan-Streamer v0.1（`2606.25041`）

- **原生流式**单 Transformer：视觉/音频/文本的输入输出 token 交错，块因果注意力；**不依赖任何外接 VAD/ASR/LLM/TTS/动画/视频生成模块**，感知-推理-生成-时机-轮转-跨模态同步全部联合学习；流单元短至 **160 ms @25fps**。
- 映射：与 Talker-T2AV 同属"任务定义反转"（§五联合生成）；对级联派（我们 CyberVerse）是**对立面标杆**——引用时注意立场。

### AVTR-1（`2609.22913`）

- **开放栈**：153M 自回归流匹配运动生成器（条件 = 双方音频），音频编码器**自蒸馏**流式化；把分块生成变成**由外部语音 Agent 驱动**的连续同步音视频流；**解析推导用户侧延迟界**并用两个商用语音 Agent 验证；数据中心与**消费级 GPU** 都实时；并指出常规听者指标不能证明交互质量（摘要截断处）。
- 映射：与我们 CyberVerse 工程主线（外接 TTS、打断止声四版本、调度）是**直接同路人**；其"常规指标不建立交互质量"与我们评测口径裂缝同源。
