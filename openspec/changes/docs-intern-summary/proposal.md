# Proposal: docs-intern-summary（总结.md 单篇 change）

## Why

伞 change 登记表 #8，也是整套文档体系的收口篇。它承担三个职责：**给读者（自己）一张总图**（做了什么、成果有多少）、**沉淀方法**（哪些做法值得复用）、**产出发文方向**（选题漏斗 + 候选方向的证据盘点 + 撞车扫描 + 决策建议）。

按本轮决定（方案 B），《数字人行业全景》的**选型结论**与**趋势判断**汇入本篇——因为那两件是"判断"，与"事实"分家。

## What Changes

- 汇总 1–7 篇的量化成果（**只搬运不新造证据**），逐项标注来源文档
- 汇入《数字人行业全景》的选型结论与趋势判断
- 整理工作方法与时间轴（任务树、实验记录规范、证据等级、[shared] 协作、探针与消融方法）
- 产出选题漏斗与候选方向：每个候选给"证据资产负债表"（有什么证据、缺什么），并用论文库做 related-work 撞车扫描
- 整理结果在对话中提交审核（不写入仓库），审核通过后写正文
