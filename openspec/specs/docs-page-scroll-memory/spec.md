# docs-page-scroll-memory Specification

## Purpose
定义文档页（`/management/docs`）正文滚动位置的记忆与恢复行为：刷新页面或在不同文档之间切换后，阅读位置不丢。
## Requirements
### Requirement: 刷新后恢复滚动位置

文档页 SHALL 记录当前文档的正文滚动位置，并在页面刷新或重新进入同一篇文档时恢复该位置。

#### Scenario: 刷新同一篇文档
- **WHEN** 读者在某篇文档上滚动到中部，然后刷新页面
- **THEN** 正文自动回到刷新前的位置

#### Scenario: 首次进入某篇文档
- **WHEN** 读者第一次打开某篇从未读过的文档
- **THEN** 正文停在顶部，不出现跳动

### Requirement: 切换文档时按文档分别记忆

滚动位置 SHALL 按文档分别记忆：从 A 篇切到 B 篇再切回 A 篇时，A 篇恢复到之前的位置，B 篇从其自己的记录（或顶部）开始。

#### Scenario: A → B → A
- **WHEN** 读者在 A 篇滚到中部，切到 B 篇（停在顶部），再切回 A 篇
- **THEN** A 篇回到中部，B 篇的位置互不干扰

### Requirement: 恢复行为不影响正文锚点链接

滚动位置恢复 SHALL NOT 干扰正文内的锚点跳转（`[文字](#slug)`）与站内路由跳转：锚点跳转后仍能正常定位到目标小节。

#### Scenario: 锚点跳转后切换再返回
- **WHEN** 读者通过文内锚点跳到某小节，随后切到另一篇再切回
- **THEN** 位置按记忆恢复，锚点跳转本身仍正常工作
